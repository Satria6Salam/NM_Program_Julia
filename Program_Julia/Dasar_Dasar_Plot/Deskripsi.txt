1. Membuat plot baru vs menambah ke plot yang sudah ada

    > plot(args...; kw...) → membuat plot baru.
    > plot!(args...; kw...) → menambah (overlay) ke plot yang sudah ada ("modify current").
    > Alternatif: plot!(plt, args...; kw...) jika kamu punya objek plot plt.

2. Bentuk input yang bisa dipakai
Beberapa cara memasukkan data ke plot:

Bentuk	                Contoh
Vektor                  y saja	plot(rand(10)) → asumsi sumbu x = 1:10
Pasang                  x dan y	plot(1:10, rand(10))
Banyak seri sekaligus	plot(rand(10,5)) → 5 seri dengan x = 1:10
Fungsi terus domain	    plot(sin, 0:0.1:π)
Gabungan fungsi/fungsi	plot([sin, cos], 0:π)

3. Keyword / argumen untuk kustomisasi
Beberapa keyword umum:

    xlabel, ylabel: label untuk sumbu x / y.
    title: judul plot.
    legend: posisi legend (misal :topright, :topleft dsb).
    color (alias c), marker: warna garis atau marker.
    line: pengaturan garis (misal style, width).
    xlims, ylims: batas sumbu x / y.
    xticks, yticks: di mana tick-nya.
    Ada juga alias-alias pendek (misal c = buat warna).

4.  Plot Skala Logaritmik
    Skala logaritmik digunakan untuk data yang tumbuh / mengecil sangat cepat.
    xscale dan yscale bisa diatur ke: log10 atau :ln.
    jenis:
    >   Semilog-x --> xscale=:log10
    >   Semilog-y --> yscale=:log10
    >   Log-Log --> keduanya logaaritmik
